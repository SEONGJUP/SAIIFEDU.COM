# saiifedu.com — 세이프에듀 랜딩페이지

㈜새임(SEIIM)의 AI 스마트 안전보건교육 시스템 **세이프에듀(SAIIFEDU)** B2B 랜딩페이지입니다.
빌드 도구 없는 정적 사이트라 어떤 정적 호스팅(GitHub Pages, Vercel, S3 등)에도 그대로 올릴 수 있습니다.

## 구성

```
index.html                 랜딩페이지 (디자인 시안 3종 전환 가능)
compare.html               시안 A·B·C 나란히 비교 (내부 검토용, noindex)
assets/css/base.css        공통 레이아웃·컴포넌트
assets/css/styles.css      시안별 색·모서리·레이아웃 토큰
assets/css/pretendard-embed.css  Pretendard 서브셋(CDN 실패 시 대비)
assets/js/main.js          5단계 탭, 다국어 자막 미리보기, 상담 폼 검증, 시안 선택 바
assets/img/                로고, 서비스 화면, 현장 사진, 문서 샘플, 영상 썸네일
```

## 디자인 시안 보기

- `index.html#a` 코퍼레이트 · `#b` 세이프 틸(기본) · `#c` 현장 인더스트리얼
- 화면 하단 **디자인 시안** 바에서 바로 전환, 또는 `compare.html`에서 세 시안을 나란히 비교

로컬 미리보기: `python3 -m http.server 8000` 후 http://localhost:8000

## 시안 확정 후 할 일

1. `index.html` 상단 스크립트의 기본값 `'b'`를 선택한 시안으로 고정하고, 하단 `.picker` 블록 삭제
2. `assets/js/main.js`의 "디자인 시안 선택 바" 부분, `base.css`의 `.picker` 스타일, `styles.css`의 미사용 시안 블록 삭제
3. `compare.html` 삭제
4. 상담 폼 접수 연동 (`main.js`의 `TODO` — 폼 서비스 또는 사내 API)
5. 파비콘, GA/네이버 애널리틱스, 네이버 서치어드바이저 등록
