# saiifedu.com — 세이프에듀 메인 홈페이지

㈜새임(SEIIM)의 AI 스마트 안전보건교육 시스템 **세이프에듀(SAIIFEDU)** 소개 페이지입니다.
태블릿으로 진행하는 교육이라는 점이 한눈에 보이도록, 제품 판매 페이지처럼 CSS로 그린 태블릿을 중심에 두고 스크롤 인터랙션으로 기능을 보여줍니다.
빌드 도구 없는 정적 사이트라 GitHub Pages, Vercel, S3 등 어디든 그대로 올릴 수 있습니다.

## 구성

```
index.html                       메인 페이지
assets/css/site.css              전체 스타일 (CSS 태블릿·앱 화면 포함)
assets/css/pretendard-embed.css  Pretendard 서브셋 (CDN 실패 시 대비)
assets/js/site.js                스크롤 인터랙션, 5단계 화면 전환, 언어 선택, 카운트업, 상담 폼 검증
assets/img/                      로고, 서비스 화면, 현장 사진, 문서 샘플, 영상 썸네일
```

## 섹션과 인터랙션

| 섹션 | 내용 | 인터랙션 |
|---|---|---|
| 히어로 | "세이프에듀 · 교육부터 서류까지, 알아서 완성해드릴게요." | 스크롤하면 기울어진 태블릿이 일어서며 확대 |
| 한 문장 소개 | 좌석마다 태블릿 한 대… | 스크롤에 따라 단어가 하나씩 밝아짐 |
| 핵심만 빠르게 | 1:1 태블릿 · 6개 언어 · AI 집중도 · 70점 · 문서 · DB | 가로 스냅 캐러셀 |
| 5단계 교육 흐름 | 착석·로그인 → 입과 → 영상강의 → 테스트 → 수료 | 태블릿이 고정되고, 스크롤 단계마다 화면 전환·서명 애니메이션 |
| 다국어 | 같은 표준 교안, 각자의 언어로 | 언어 버튼을 누르면 교안 제목·자막 변경 |
| AI 집중도 | 시선 추적·자동 일시정지·리포트 | 스캔 라인, 집중 안내 토스트 |
| 문서 자동화 | 교육일지·참석자 명단·사진대지 | 스크롤하면 문서 3장이 부채꼴로 펼쳐짐 |
| 관리자 기능 | 대시보드, QR·TBM, PPT 교안, 협력사, 중처법 | 벤토 그리드 |
| 도입 사례 | 97% · 100% · 92%, 수상·선정 | 숫자 카운트업 |
| 영상 · 상담 | YouTube 링크, 도입 4단계, 상담 폼 | 플로팅 라벨 폼 |

`prefers-reduced-motion` 사용자에게는 모든 움직임을 끄고 최종 상태로 보여줍니다.

로컬 미리보기: `python3 -m http.server 8000` 후 http://localhost:8000
